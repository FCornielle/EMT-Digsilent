# Study README Template

Every study directory must contain a README using the following review order.
Sections may be expanded, but their engineering intent must not be removed.

1. **Status and maturity** — planned, engineering basis, model implemented, or
   verified baseline.
2. **Industrial question** — the equipment/system decision supported by EMT.
3. **KPIs and limits** — definitions, units, bases, and source of acceptance
   criteria.
4. **PowerFactory model** — topology, stable object names, model classes, and
   native diagram.
5. **Input basis** — example, assumed, calculated, measured, utility, or vendor.
6. **Scenario matrix** — events, locations, point on wave, scatter, and sweeps.
7. **Detailed procedure** — numbered and reproducible.
8. **Result contract** — object, variable identifier, units, and sampling.
9. **Verification** — analytical comparison, numerical convergence, and model
   fidelity checks.
10. **Figures** — native one-line, parameters, waveforms, comparison, ranking,
    and verification.
11. **Interpretation** — physics, uncertainty, limitations, and decisions.
12. **Execution** — commands, scripts, outputs, and rerun order.
13. **Completion gate** — objective evidence required for “Implemented”.
14. **References** — official documentation and applicable technical standards.

Planned studies must not contain fabricated result values or result-looking
plots. They should state what will be measured and how completion will be
verified.
