# Historical PowerFactory UI Captures

This directory preserves the two PowerFactory 2024 screenshots that originally
sat beside the repository instead of inside it. They are retained for project
provenance and are not simulation results:

- `powerfactory_2024_empty_workspace.png` records the empty PowerFactory 2024
  workspace used during early API connection checks.
- `legacy_blank_single_line_export.png` records an early blank graphic export,
  retained as diagnostic evidence of the headless Graphics Board limitation.

Verified network diagrams and EMT result figures are documented within the
corresponding study README files.
