# Study 07 — SLG, LL, LLG, and Three-Phase Faults with Variable Clearing

> **Status: planned.** This is the shared event foundation for protection and
> TRV studies.

## Industrial question

How do fault type, inception angle, location, resistance, and clearing sequence
affect instantaneous current, DC offset, thermal duty, voltage recovery, and
equipment/protection stress?

## Scenario matrix

1. SLG, LL, LLG, and three-phase faults;
2. sending-end, midpoint, receiving-end, and bus locations;
3. fault resistance and source-strength sweeps;
4. inception point on wave;
5. main and backup clearing times;
6. simultaneous and pole-discrepant breaker opening;
7. reclosing and permanent/transient fault alternatives.

## Main KPIs

- first-cycle and absolute peak current;
- symmetrical RMS and DC-offset time constant;
- current integral and I²t;
- minimum voltage and recovery time;
- negative- and zero-sequence content;
- breaker/protection operating margins.

## Required figures and completion gate

Required outputs include the native one-line, event timeline, instantaneous
currents/voltages, fault-type comparison, location/clearing heatmaps, sequence
components, and time-step sensitivity. Completion requires analytical
short-circuit comparison and deterministic event-order tests.
