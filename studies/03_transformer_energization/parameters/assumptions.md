# Study 03 parameter assumptions

This is a declared educational 100 MVA, 230/34.5 kV benchmark. Ratings,
short-circuit strength, losses and excitation inputs are not tied to a named
transformer or manufacturer report. The residual vectors are balanced for the
three-limb representation. The baseline uses simultaneous pole closing and no
hysteresis so that saturation, point on wave and residual flux remain directly
interpretable. See `configs/base.yaml` for the machine-readable source of truth.
